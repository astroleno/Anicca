# 以细微交互代替说明文字（2026-11-18）

方向：极简、轻盈、软糯，保持心流沉浸。核心是正反合；乔哈里与多维是延展，只在用户选择后出现。
原则：屏幕上不新增解释性文字；能用液滴、位置、明暗和时间表达的，就不用一句话说明。屏幕阅读器仍获得完整的手势与状态描述。

## 为什么这样做

- **正反合是动作，不是菜单**：分裂、牵引、融合本来就由液态渲染器承担（拖近时的 `data-liquid-partner` / `data-liquid-contact` 与停留确认已经存在），这轮主要拿掉与之重复的文字，让液滴自己表达。
- **位置即含义**：合落在来源下方、来源退后，读者不必看标签也能看出谁从谁而来。
- **主次之分**：参考视频里一颗主滴、几颗卫星的结构，阅读不再是“正文浮在影子上”，而是所读的想法就在正文背后，邻近想法围绕它；切换由液体完成，文字晚一步到，空间上不断开。只在阅读时启用，全景舞台保持不变，避免丢掉正反合的整体结构。
- **乔哈里不另起概念**：项目已有乔哈里模板与按维度落位；缺的只是舞台上看得见的方向。场只在用户选定维度后常驻，不打扰只用正反合的人。

## 验证

- `npm run check`：96 个测试文件、725 项测试通过；lint 0 error（26 条既有 warning）。
- 新增或调整的测试：合的落位、等待液滴不带说明文字、来源退后的注意力值、阅读顺序（旧实现下会失败）、全景不重复摘要（旧实现下会失败）、`StageField` 6 项、DialogueShell 中“在舞台上点乔哈里区域设定下一次展开”。
- 视觉检查：`reading-continuity`、`selection-intent`、`surface-controls` 在本地开发服务上通过；桌面 1440×900 与 390×844 触屏截图人工检查，页面无运行时错误。
- 阅读即聚焦：`readingOrbit` 6 项单元测试（正左反右、来源在上、窄屏最多 4 颗、单侧最多 3 颗、两侧平衡）；BubbleStage 中卫星立即读取、主滴不可交互、按下与双击不收起阅读或分身；DialogueShell 中“点卫星读邻近想法且不退出阅读”。`reading-continuity` 视觉检查改为：阅读时必须出现主滴与卫星，关闭后每颗种子回到原位（< 4px）。逐帧截图确认先液滴交换（约 110ms 内）、后正文浮现。
- 提示淡出：合成后约 7.5 秒，`[data-whisper]` 的 computed opacity 在桌面与手机上均为 0。
