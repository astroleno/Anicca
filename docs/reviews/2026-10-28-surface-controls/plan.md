# 舞台、输入与基础操作收敛

## 目标与既有决定

按本轮截图和用户要求迭代；不增加卡片，保留 sketch1638178 的低饱和材质、软边、融合形体与已有手势。桌面默认 TSL 自动，移动默认原版，手动选择与自动回退不变。用户已授权实现、验证、commit、push 和两个公网入口同步；使用当前 main 工作空间，不启动实现子 agent。

## 模块与接口

- 导航：DialogueShell 提供单行布局容器与舞台视角控件插槽。WorkspaceBar、PerspectiveControls、BubbleStage 的导航控件参加同一布局，标题、提示与操作不再各自争抢绝对定位区域。导航及舞台操作标记为标签避让区。
- 字体与控件：在现有 CSS 模块中定义正文、操作、辅助三档，正文保持可读行距。输入使用直线底边和底边焦点提示；文字按钮保持 44px 命中区，移除重复胶囊、圆框和非必要描述层级。
- 基础操作：正反推演、极性分裂、组合在阅读顶部同排；舞台当前种子也提供同级入口。极性入口复用原有维度选择和生成接口，保留原角度、返回、Escape、阅读位置与合成后继续展开语义，不新增生成模型或数据协议。
- 等待表皮：DOM 表面标记经过 MetaballSurfaceRect / DialogueMetaballNode / LiquidFrame 传入两种渲染器。仅待生成种子及追问来源增加轻微表面噪波，成功、取消、失败后随对应状态消失；减少动态时冻结噪波，不引入体积采样。
- 表面交界：复核前后表面覆盖、法线与有限步进收敛；两后端采用一致修复，保留外轮廓软边与环形孔洞。以实际融合、拉开以及遮挡帧验证，不能用整体模糊遮住白线。

## 验收

1. 桌面、320/390px 手机、768px 平板及横屏无导航/文字遮挡；输入无圆角双框，键盘焦点可辨，正文可选句。
2. 无需进入二级设置即可找到极性分裂；与正反、组合相同层级；原有维度选择及返回仍可用。
3. 生成等待、取消、失败恢复时噪波状态正确；原版、TSL WebGPU / WebGL2 都能渲染，减少动态保留静态反馈。
4. 融合、分离、第三个球遮挡场景无白色断线，软边、颜色与孔洞不退化。
5. 全仓检查、生产构建、两端选句→追问→极性→正反→合成→刷新→继续展开；验证手动切换和回退。
6. 腾讯云候选验证后切换，两个域名保留各自地址栏并复核；提交仅包括本轮代码与验证资料，不包含现有无关改动。

## 验证环境

沿用项目隔离浏览器验证脚本；Browser plugin not available，使用现有 Playwright 仅完成必需的渲染与交互验证，不操作用户实际工作区。移动视口不冒充本轮真机复测。
