# 本轮修复约定

用户已授权实施本轮评审的 2 项 P2、1 项 P3，并 commit、push、同步公网。沿用已有 main 与腾讯云候选版本验证、原子切换、双域名入口；不创建分支、工作树或实施子 agent。

## 目标、模块与接口

- `SeedInspector` 增加可选 `onReadingIntent()` 回调。正文中的鼠标滚轮、触摸/指针阅读和键盘滚读表达阅读意图；原始 scroll 仍只记录位置，布局恢复和输入框自动露出不改变注意力归属。`DialogueShell` 复用现有 attentionVersion，用户继续读时保存回应并保持原文、位置与焦点；没有后续操作时仍自动进入回应。保存而未自动打开的回应，在当前阅读的文字工具行提供“阅读新回应”入口，不加卡片；当前草稿被编辑时继续保留新草稿与写作目标。
- 阅读顶部采用独立于正文滚动区的轻量文字工具行，返回按钮保持至少 44px 命中高度。标题和正文仍可滚动，无卡片、边框或新动画；极性返回按钮仍只退出极性，保留原阅读位置与焦点。保持现有 `dialogue-panel` 为实际滚动区，兼容阅读位置持久化和既有验收接口。
- `WorkspaceBar` 的改名会话绑定打开时的工作区 ID；当前 ID 变化立即隐藏旧表单、重置会话，提交再次校验归属。普通保存、取消、更多菜单与草稿恢复保持原路径，不增加确认层。
- 不更换材质、配色、渲染后端默认值和手势；桌面 TSL 自动、移动原版、手动选择与原版回退不变。
- 调查发现上一提交的视觉 CI 因串行软件渲染超过现有 30 分钟总时限而失败。沿用已有 viewport/scenario 过滤接口分为布局、渲染、阅读/菜单、注意力、思考主链五组，最多两组同时运行；保留全部覆盖与现有超时上限，分别留存证据，不通过加时或删检查掩盖问题。

## 验收与交付

- 组件/集成测试：等待时继续读、程序滚动对照、无操作自动打开、改草稿、取消、显式退出；主动打开已保存回应；A 未提交改名后新建/切换 B、返回 A、普通保存/取消；极性、菜单 Escape 逐层关闭。
- 实际浏览器：桌面/移动触摸模拟的滚轮、触摸滑动、键盘读文；回应到达保持原文与阅读锚点、焦点，入口可打开保存回应；长文中段/底部返回按钮始终可见可命中，退出重开和刷新恢复阅读；工作区名称提交归属。补 320、平板/中等宽度与横屏边界。
- 全仓 lint、生产与测试类型、单元测试和 Linux `/Anicca` 生产构建；候选版本验证后再切换公网。两域名桌面/移动的选句、拖拽、极性/正反、合成、刷新及合成后继续展开完整流程；保留手动渲染与自动回退。
- 只暂存本轮源码、测试、评审及修复证据文档；保持已有无关修改。提交、推送并确认公网运行版本与提交对应。真机、系统软键盘和 GPU 持续性能未实测时如实说明，不用模拟结果代替。
