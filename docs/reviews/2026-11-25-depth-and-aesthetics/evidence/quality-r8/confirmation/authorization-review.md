# 馆内播放许可为何在审校后被扩大

合成评测请求 `r8-after-holdout-06-1` 对应 `c7888fa` 的已揭回归题 holdout-06、33 题匿名卷 q08。模型收到的六个提示均含“受限内容改成摘引、转述或其他形式，或改变用途、渠道、受众，都须核对相应许可”。两份来源分别说明首页希望留住第一人称证言，以及“她签的只是馆内播放原声”。模型检索到的候选卡和实际入选卡均为空，本次走常规正文审校。规则卡缺席并未移除上述授权检查。[冻结请求及 HTTP 结果](../confirmation-regression/after/responses/holdout-06-synthesis.json) · [阶段跟踪](../confirmation-regression/after/traces.json)

| 次序 | 当次模型回包与处理 |
| --- | --- |
| 1 · 初稿 | 已写出“今晚公开版应撤下原声，首页用文字摘引替代”。越权决定起于初稿。 |
| 2–3 · 校正稿与补段 | 177 字的校正稿仍主张将叙述改成文字摘引。长度不足触发一次补段，新增 56 字，末句称“两侧因此各退到各自许可的范围内”。全文通过格式检查。 |
| 4 · 首次正文审校 | 实质判定为 `pass:false`，提出“阻止录音”缺少依据、摘引能保留语调未经证明、甲方未谈许可三条意见。审校明示可改成“乙的许可边界得到遵守，甲的一手语调诉求以摘引形式部分保留”。这条修复方向继续认可公开摘引。 |
| 5 · 正文改写 | 230 字的改写采纳了三条意见，保留“今晚公开版可把首页改成文字摘引，并明确标注转述”，并写明“乙的许可边界得到遵守”。 |
| 6 · 独立复审 | 复审给出 `pass:true` 和空问题列表。`sourceB` 引用“她签的只是馆内播放原声”所在的原句，`consequence` 引用“今晚公开版可把首页改成文字摘引，并明确标注转述”所在的原句。两段逐字匹配各自文本，审校却认可由前者推得后者。接口返回 HTTP 200。 |

这是一次实质判断错误。审校识别了改变录制管理措施和语调表达的风险，却把撤掉可识别的声音当成公开使用文字证言的充分条件。材料只支持馆内播放原声。对网页摘引标注出处或说明转述，均没有补足新的形式和受众所需的许可。正文规则、连续引文和一次审校修复均已实际执行。后续需要检验的是审校能否把**每个拟议的对外使用动作**与授权依据逐项对应，并允许授权范围相符时直接行动。该题可计为已交付可读正文，授权结论仍按已封存的严重判词处理。[封存判词](judgments.json) · [揭盲结果](results.md)
