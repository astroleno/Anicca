### 5　按实际决策检索策略卡

1. **先固定对照集**。在策略卡测试中写入约 30 条自然负例，含 README 的六句和上轮已通过的个人问题。覆盖家庭与工作、个人创作、关系用语、聊天资料及记忆；也保留普通的不含歧义词的问题。对照当前版本，记录已通过与误命中。为缓存、预算、恢复各配领域正例，尽量复用负例用词，改变实际决策。例：“三个晚上要在旧工具维护和新功能验证之间如何分配？”应命中预算；“撤权后访问控制的快取何时应回源？”应命中高风险缓存；“删除生产历史数据前如何验证备份可恢复？”应命中高风险恢复。
2. **检索接口与上下文**。`policyCards.ts` 保留单字符串调用、上限、排序与风险分类。合成路由将根输入、补充联系、两份来源以独立片段传给检索；在每个片段内判断是否具备领域对象与具体决策，再按原优先级合并去重。任一片段自身足以支持场景就保留其卡；两个无关片段各出一个词不能拼成领域证据。技术同义表述应可独立成立。规则以领域证据为基础，避免按“家人”“小说”等题材建立排除清单。仅修改检索、路由接入及必要测试，保持生成请求与响应格式。
3. **独立验收**。逐条核对负例为空且无高风险，正例命中预期卡及风险级别。用真实合成路由的请求结构验证三类组合：两句家庭片段各空且组合为空，含明确领域来源的混合请求仍命中，一个普通补充不改变有效卡的排序。保留既有三套共 36 条的卡片 ID、顺序和风险分类，运行受影响的检索、路由测试与仓库常规检查。记录通过数、仍失败输入及检索边界；最终回答质量另需生成评测。

### 6　合流舞台的三级可见直径

1. **角色与尺度**。只在普通舞台显示当前合、或展开其来源时使用：当前合为焦点，两颗直接父节点为直接关系，其他可见种子为远景。以当前焦点可用直径为基准，三级可见直径目标为 **1∶0.7∶0.45**，同级来源不因正反角色出现量级差异。保留原阅读主滴、卫星以及生成中的液桥。这里的直径指液滴本体，不含标签、触摸热区和柔边外的光晕。
2. **共用几何**。在 `BubbleStage.tsx` 与 `DialogueMetaballLayer.tsx` 共用同一关系分级和可见尺寸，使 DOM 平面降级、液体后端、标签锚点与避让读取一致。独立保留可点区域，远景缩小时仍可操作；避让考虑其他液滴和标签，不能让透明背景或更大的热区抢点。把本功能重复的 640 宽判断统一到同一语义：舞台可用宽度控制舞台几何，视口宽度仍可控制页面工具栏；同为 640 的阅读高度条件无关。仅在引线或布局直接妨碍本项验收时调整。
3. **320 宽主验收**。Sol 对普通合流与展开来源分别保存稳定彩色原图、同帧灰度遮字图及实际直径。用一致可复核的轮廓口径记录各颗的可见直径及相对焦点比例，允许柔边与轻微形变，并说明偏差。遮去标题、角色字、工具栏上下文及其他直接提示，保留液滴的位置与大小。先交给 Astra 两张灰度图；Astra 在看到标签、节点身份或对应彩色图前记录各图的焦点、两个直接来源及远景位置，再揭示答案核对。判错则本批尚未通过；DOM 焦点属性仅用于核对。该判读是独立评审，不代替真实用户测试。
4. **还原与回归**。在彩色有字的两个状态核对节点身份、标签和可点击区域；用真实坐标一次点开两颗来源，返回后仍能点中另一颗。320 宽检查阅读正文稳定及三项基本操作保留，390、1440 宽回归思考流程，430 宽复查空白区不抢点。通过当前可用液体后端和 DOM 降级核对体量与命中几何，运行布局、渲染相关测试与仓库常规检查。记录浏览器、后端、视口、提交和截图；另记引线、卫星截断、首屏操作可发现性观察，区分尚待用户或设备验证的判断。

#### 合流菱形落位与连续尺寸

- **几何接口**。在 `synthesisStageGeometry.ts` 接收舞台可用矩形（宽、高及工具栏/输入区占用）、可见节点数量、焦点与两来源 ID，返回按节点 ID 对应的默认中心与可见直径。普通合流及展开来源共用；阅读、生成液桥、极性场按既有语义。以实际投影后的屏幕坐标验收：默认视角下焦点处于可用舞台中线以下、距屏幕中轴不超过屏宽的 15%（320 宽为 48 px），两来源分别在它左上和右上。同级远景退至侧缘或上缘，离开三颗主滴形成的三角内部；上轴仅可容纳已有远景种子，不为补齐形状虚构节点。取用横向及下半空间，预留标题和点击区域。
- **持久布局与手势**。`placeSeeds` 与 `ensureStageNodePositions` 会把默认位置和用户落点写入同一 `nodePositions`，旧记录无法可靠识别拖动来源。采用合流专用视图的默认位置及按合节点、视口模式保存的拖动覆盖；进入合流不回写或迁移旧宽/窄舞台位置。拖动结束沿用现有坐标转换保存该合流视图的用户落点，重新打开、缩放、从阅读返回时保持；退出合流还原普通舞台，既有全局拖动、预览/取消与重新排列语义保持。新覆盖是可选数据，明确定义旧快照、无覆盖、撤销与重排路径。默认构图指标只约束未手动移动的视图。
- **连续尺度**。以可用面积和数量共同决定基准直径，例如 `clamp(min, k × sqrt(availableArea / count), max)`，宽窄范围按可用空间校准，保持可见直径目标 1∶0.7∶0.45 与约 44 px 各自可点热区。由 `BubbleStage`、投影/液体与平面降级共享同一尺度来源和标签避让几何。固定面积时，4→5 的目标尺寸变化不超过平方根模型约 11%（测量允许 1 px 取整），不再发生 116→84 的整档跳变。常规动态模式应在同一已挂载节点上平滑改变可见轮廓；减少动态效果时直接稳定落位。
- **验收**。320×568 在刚合流、展开来源分别留有字、灰度遮字同帧截图，记录可用矩形与投影后各中心。Astra 先盲判焦点/两来源/远景，再按屏幕中轴、上下及左右关系量测；保留上轮半对比度测轮廓方法核对体量。真实平面降级走一次从 4 个可见节点到 5 个的同一舞台变化，记录同一节点的开始、中间、最终可见直径及时间，至少观察到一个介于两端的中间帧，核对最终命中和标签位置。不能用两个静态场景或 CSS 声明代替。验证沉浸期间可用面积变化、旧工作区、手动拖动及刷新；390、1440 及 430 回归既有路径。
