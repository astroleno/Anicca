# 六项修复的模块与验收约定

本计划承接已批准的 F-01–F-06，不调整视觉体系、图结构、生成契约或现有手势。仅修复恢复与交互闭环；完成本地和公网验收后 commit/push。

| 项目 | 模块与接口 | 行为与验收 |
| --- | --- | --- |
| F-01 维度草稿 | `PerspectiveControls` 按 workspaceId 持有草稿；`PerspectivePanel` 接收草稿和变更回调。独立、版本化本地草稿 journal，不写入已保存的 thinkingSpace。 | 观察往返、普通关闭、重开、切工作区均保留各自草稿；仅保存应用新维度，取消丢弃；不串工作区，不覆盖旧种子框架。 |
| F-02 移动复位 | 思考空间的纯视角区新增文字动作，发送复位请求给 `BubbleStage`，复用既有 `resetView`。 | pan/zoom/orbit 一并恢复；不重排种子、不改框架与生成入口；桌面和移动可达，不新增卡片。 |
| F-03 阅读恢复 | 独立 reading journal 与工作区绑定；保存阅读实例、节点读位和原文字符锚点。`SeedInspector` 负责 DOM 锚点捕获/恢复，hook 负责工作区生命周期和 pagehide flush。 | 刷新恢复同一对象与原文位置，换宽度按文字锚点恢复；主动关闭保持关闭；分身、合、切换工作区不串状态；旧数据无此 journal 时兼容。 |
| F-04 恢复提示 | 保留现有错误分类、重试回调与草稿保护；修改 `DialogueShell` / `DialogueComposer` 面向读者的说明。 | 不指向密钥/baseURL/不存在的模型设置；明确“重试上次”区别于生成当前草稿；失败、取消、迟到结果的图保护不变。 |
| F-05 搜索空态 | `SeedInspector` 区分全部候选与过滤结果，提供就地清空搜索。 | 无匹配不声称没有种子；清空恢复列表，不发请求、不换组合来源。 |
| F-06 阅读动效 | 区分键盘/辅助激活与指针；`SeedReadingContent` 支持即时呈现。 | 键盘及阅读恢复不播放位移入场，指针保留短而轻的过渡；焦点、读位、退出惯性保护和 reduced-motion 不退化。 |

不改既有快选即合成、不新增假设性需求。仍保留桌面 TSL 自动、移动原版、手动切换与自动回退。

验收：状态 journal 和生命周期回归、受影响组件与全仓检查、Linux 生产构建；桌面与移动触摸视口执行首访→选句追问→极性→正反→拖拽合成→刷新→从合继续，并验证六项恢复场景。先在候选发布上完成本地流程，再切换共享腾讯源站，最后分别验证两个保留域名的公网入口。保留原发布可回滚，不改现有入口反代。
