# 完成目标实施计划

## 📋 目标概述

实现一个完整的对话式球体系统，具备以下核心功能：
1. **分裂功能**：Chat UI 输入后，使用 AI 生成正反两个子球（带标签和内容）
2. **合并功能**：子球融合时，调用 Chat API 使用"合.md"提示词生成合并内容
3. **标签显示**：球的序号标签显示为 AI 生成的摘要词（≤4字）
4. **上下文管理**：集成上下文管理机制，支持对话历史的回溯和利用

## 🔧 技术细节

### API 调用流程

#### 分裂流程
```
用户输入 → Chat API（使用"正.md"） → 生成正向内容和词
         → Chat API（使用"反.md"） → 生成反向内容和词
         → 更新父球 content/summary
         → 调用 split(ballId, { positive, negative })
         → 创建两个子球（带 label、content、summary）
```

#### 合并流程
```
两个球靠近 → merge(ballA, ballB)
           → 调用 Chat API（使用"合.md"）
           → 构建提示：假说A + 假说B
           → 生成合并后的内容和摘要
           → 创建新球（带合并后的内容）
           → 删除原两个球
```

### 数据结构变化

**Before**:
```typescript
Ball2D {
  id: number
  label?: string  // 简单标签
  ...
}
```

**After**:
```typescript
Ball2D {
  id: number
  label?: string      // 摘要词（≤4字）
  content?: string    // 完整内容
  summary?: string    // 长摘要（≤30字）
  nodeId?: string     // branchGraph 节点 ID
  ...
}
```
